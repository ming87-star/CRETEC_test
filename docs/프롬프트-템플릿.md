# 촬영 프롬프트 템플릿

상세페이지 섹션마다 필요한 사진이 다르다. 공통 뼈대는 고정하고, **컷마다 망가지는
지점이 다르므로 그 지점을 집중적으로 지정한다.**

길이는 기준이 아니다. 짧아서 나쁜 것도, 길어서 좋은 것도 아니다. 그 컷이 실패하는
자리를 막았는가만 본다.

프롬프트는 **한국어로 쓴다.** 검증된 형태가 한국어고, 사람이 읽고 고치기 쉽다.
맨 끝의 영문 키워드 줄만 영어로 둔다.

제품 사진은 **프롬프트에 붙이지 않고 따로 첨부한다.** 프롬프트는 그 첨부물을
가리키기만 한다.

## 2. 컷마다 망가지는 지점

프롬프트를 어디에 쏟을지는 이 표가 정한다.

| 컷 | 망가지는 지점 | 반드시 지정할 것 |
|---|---|---|
| **히어로** | 배경과 제품의 광원 방향이 따로 놀아 합성처럼 보임. 카피 자리가 안 남음 | 광원 방향을 배경·제품에 같은 문장으로 못박기. 여백 위치와 크기 |
| **매크로 디테일** | 없는 구조를 지어냄. 구멍·나사산 개수와 간격이 바뀜 | 외형 기준 전부를 수치로. 심도 범위. 금속 절삭면 성격 |
| **제품 단독컷** | 비율이 미묘하게 틀어짐. 바닥 그림자가 붕 뜸 | 접지면과 그림자 방향. 정면/사분면 각도 |
| **사용 장면** | **손가락 개수와 그립이 무너짐.** 얼굴이 들어옴 | 손 개수, 어디를 어떻게 쥐는지, 프레임에 손목까지만. 얼굴 제외 |
| **비교컷** | 두 제품의 조명·각도·거리가 달라 비교가 성립 안 함 | 같은 조명, 같은 각도, 같은 거리, 같은 바닥면임을 명시 |
| **구성품 배치** | 구성품 개수가 멋대로 늘고 줆 | 품목 이름과 개수를 그대로 열거. 그 외 추가 금지 |
| **배경만** | 제품이나 공구가 들어가버림 | 제품·도구·사람 일절 없음. 합성될 자리를 비워둘 것 |

정밀 가공이 상품인 컷에는 구조 묘사를 길게 쓰고, 사람이 쓰는 장면에는 손 묘사를
길게 쓴다. 반대로 쓰면 둘 다 실패한다.

## 3. 고정문

### 블록 2 — 첨부 안내
```
제품 이미지는 별도로 첨부한다.
```

### 블록 3 — 기준 이미지 고정 (기본형)
```
첨부한 제품 사진을 제품 외형과 구조의 유일한 기준 이미지로 사용한다.
실제 전체 실루엣, 비율, 표면 코팅, 색상, 재질, 로고, 브랜드명, 인쇄 문자와
그 위치를 임의로 변경하지 않는다.
```

구조가 상품인 컷에서는 여기에 **기획 단계의 「상품 외형 기준」 표**를 문장으로
풀어 덧붙인다 — 직경과 높이 비율, 외벽 두께, 개구부의 위치·크기·형태, 체결
구멍의 개수·위치·간격, 모서리 형상, 가공 흔적.

### 블록 4 — 재해석·추가 금지 (고정)
```
제품을 새로운 형태의 공구로 재해석하지 않는다.
실제 제품에 없는 구멍, 홈, 슬롯, 절삭날, 돌출부, 나사산, 볼트, 패턴, 로고 또는
문자를 추가하지 않는다. 첨부 제품에 존재하는 구조만 그대로 유지한다.
```

### 블록 13 — 네거티브 (공통)
```
제외 요소: 제품 형상 변경 금지, 비율 변경 금지, 구멍 추가·삭제·위치 변경 금지,
실제 제품에 없는 볼트·절삭날 추가 금지, 임의의 브랜드 로고 금지, 가짜 문자 금지,
잘못된 브랜드명 금지, 워터마크 금지, CGI·3D 렌더 느낌 금지, 과도한 HDR 금지.
```

컷별로 덧붙인다.

| 컷 | 추가 |
|---|---|
| 스튜디오 계열 | 작업장 배경 금지, 다른 공구 금지, 포장박스 금지, 스크래치·녹·지문 금지, 손 금지, 사람 금지 |
| 금속 클로즈업 | 크롬처럼 번쩍이는 표면 금지, 플라스틱 같은 금속 표현 금지 |
| 사용 장면 | 얼굴 금지, 손가락 개수 오류 금지, 팔다리 추가 생성 금지, 장갑 없는 맨손 금지 |
| 비교컷 | 두 제품의 조명 차이 금지, 크기 왜곡 금지 |
| 구성품 배치 | 명시하지 않은 품목 추가 금지 |

## 4. 채워지는 값

기획 단계에서 이미 정해진 것들이 그대로 들어간다.

| 변수 | 출처 |
|---|---|
| `{비율}` | 섹션 판형 (히어로 3:4, 포인트 1:1, 사용 장면 3:4 등) |
| `{제품명}` | 입력 |
| `{외형 기준}` | 기획 초안의 「상품 외형 기준」 표 |
| `{강조 포인트}` | 그 섹션이 팔려는 특징 |
| `{배경}` | 무채색 콘크리트 · 순백 스튜디오 · 건설 현장 · 목공 작업대 등 |
| `{조명}` | 하이키 · 하드 측광 · 골든아워 · 로우키 등 |
| `{여백 위치}` | 섹션 판형이 요구하는 카피 자리 |

## 5. 로고

AI가 글자를 제대로 못 쓴다. 실제로 `BLUETEC` 이 `BLUETH` 로 나왔다.

**우회 장치를 두지 않는다.** 생성형 AI에서 몇 번 다시 뽑아 멀쩡한 것을 고르면
된다. 각도로 피하거나 나중에 로고를 합성하는 방식은 구조를 복잡하게 만드는 데
비해 얻는 게 적다.

프롬프트에는 금지 문장만 남긴다.

```
임의의 브랜드 로고 금지, 가짜 문자 금지, 잘못된 브랜드명 금지.
첨부 제품에 실제로 있는 로고와 문자만 그대로 사용한다.
```

로고가 크게 읽혀야 하는 컷에서 계속 안 나오면 그 컷만 원본 사진을 쓴다.
규칙이 아니라 그때그때의 판단이다.

## 6. 어디서 생성하나

같은 프롬프트라도 **생성형 AI 화면에서 직접 돌린 결과가 API 호출보다 나았다.**
그래서 1단계에서 앱이 프롬프트만 내주는 방식은 비용 문제만이 아니다. 품질로도
지금은 그쪽이 낫다.

앱은 컷마다 프롬프트와 첨부할 제품 사진을 함께 내주고, 사람이 생성형 AI에서
마음에 들 때까지 뽑아 그 자리에 올린다.

API 자동 생성은 어댑터로 준비해두되, **수동 결과와 비교해보고 나서** 켠다.

## 7. 예시 — 매크로 디테일

구조가 상품이므로 **외형 기준과 심도**에 분량을 쏟는다.

> 정사각 1:1 비율의 초고해상도 포토리얼 산업용 공구 매크로 광고 사진.
>
> 제품 이미지는 별도로 첨부한다.
>
> 첨부한 제품 사진을 제품 외형과 구조의 유일한 기준 이미지로 사용한다. 실제 전체
> 실루엣, 원통 직경과 높이 비율, 외벽 두께, 개구부의 위치·크기·형태, 중앙 체결부의
> 직경과 깊이, 주변 보조 구멍의 개수·위치·간격, 금속 가공 흔적, 모서리 형상, 표면
> 코팅, 색상, 재질, 로고, 브랜드명, 인쇄 문자와 그 위치를 임의로 변경하지 않는다.
>
> 제품을 새로운 형태의 공구로 재해석하지 않는다. 실제 제품에 없는 구멍, 홈, 슬롯,
> 절삭날, 돌출부, 나사산, 볼트, 패턴, 로고 또는 문자를 추가하지 않는다.
>
> **핵심 연출** — 제품 내부 구조를 극단적으로 가까이 촬영해 정밀 가공 품질을
> 강조한다. 화면 중앙 부근의 원형 금속 체결부가 주인공이다. 홈과 절삭면, 안쪽
> 깊이감이 선명하게 보이고, 주변 작은 구멍의 내부 음영과 가공 단면까지 표현한다.
> 구멍의 개수와 배치는 첨부 사진과 동일해야 한다.
>
> **카메라·구도** — 제품 바로 위에서 25~40도 기울어진 하이앵글 초근접 매크로.
> 원통 내부가 화면 중앙과 하단을 크게 차지하고, 외벽은 좌·우·하단 가장자리까지
> 확대되어 일부가 프레임 밖으로 잘린다.
>
> **여백** — 우측 상단에 넓고 깨끗한 순백색 네거티브 스페이스를 남긴다. 나중에
> 카피를 올릴 자리이므로 아무것도 넣지 않는다.
>
> **조명** — 밝고 깨끗한 하이키 화이트 스튜디오. 대형 소프트박스를 위와 좌우에서
> 쓴 것처럼 균일한 확산광. 강한 직사광과 거친 그림자는 쓰지 않는다. 밝은 금속이
> 완전히 날아가 디테일이 사라지지 않게 하고, 홈과 구멍 안쪽에는 회색 음영을 남긴다.
>
> **재질** — 정밀 가공된 산업용 금속. 미세한 선삭 흔적과 깨끗한 반사, 홈 안쪽은
> 어둡고 바깥 모서리는 밝은 하이라이트. 코팅면은 플라스틱처럼 매끈하지 않게,
> 실제 산업용 코팅 금속의 표면 질감을 유지한다. 신품 상태로 표현한다.
>
> **초점·심도** — 매크로 특유의 얕은 심도. 중앙 체결부와 주변 구멍은 매우 선명,
> 렌즈에 가까운 하단·좌측 외벽 일부만 살짝 아웃포커싱. 핵심 구조가 흐려지지 않게 한다.
>
> **배경** — 완전한 순백색 스튜디오. 작업장, 작업대, 손, 사람, 다른 공구, 케이스,
> 포장박스는 등장하지 않는다.
>
> 정밀함과 청결함이 느껴지는 프리미엄 매크로 광고 컷.
> photorealistic, ultra-detailed macro product photography, precision machined metal,
> high-key studio lighting, clean white background, shallow depth of field, ultra high resolution.
>
> **제외 요소** — 제품 형상 변경 금지, 비율 변경 금지, 구멍 추가·삭제·위치 변경 금지,
> 임의의 브랜드 로고 금지, 가짜 문자 금지, 잘못된 브랜드명 금지, 크롬처럼 번쩍이는
> 표면 금지, 플라스틱 같은 금속 표현 금지, 스크래치·녹·지문 금지, 손 금지, 사람 금지,
> 워터마크 금지, CGI·3D 렌더 느낌 금지, 과도한 HDR 금지.

## 8. 예시 — 사용 장면

손이 무너지는 컷이므로 **손과 그립**에 분량을 쏟는다. 구조 묘사는 줄인다.

> 세로형 3:4 비율의 포토리얼 산업용 공구 사용 장면 광고 사진.
>
> 제품 이미지는 별도로 첨부한다.
>
> 첨부한 제품 사진을 제품 외형과 구조의 유일한 기준 이미지로 사용한다. 실루엣,
> 비율, 색상, 재질, 표면 코팅을 임의로 변경하지 않는다. 첨부 제품에 실제로 있는
> 로고와 문자만 그대로 사용한다.
>
> 제품을 새로운 형태의 공구로 재해석하지 않는다. 실제 제품에 없는 구조를 추가하지 않는다.
>
> **핵심 연출** — 작업자가 목공 작업대에서 제품으로 피스를 체결하는 결정적 순간.
> 톱밥이 공중에 흩날린 채 정지해 있고, 제품 자체는 흔들림 없이 선명하다.
>
> **손** — 프레임에 들어오는 손은 정확히 두 개다. 오른손은 회색 작업 장갑을 끼고
> 손잡이를 감싸 쥐며, 검지는 방아쇠에 자연스럽게 걸려 있다. 손가락은 각 손에
> 다섯 개이고 마디가 해부학적으로 맞아야 한다. 왼손은 같은 장갑을 끼고 작업물을
> 눌러 고정한다. 손목 위쪽은 프레임 밖으로 잘려 나가고 팔뚝·상체·얼굴은 보이지 않는다.
>
> **카메라·구도** — 35mm, f/2.8. 제품과 쥔 손이 화면 중앙, 작업대가 아래로 이어진다.
> 시선 높이는 작업자의 어깨 높이에서 약간 내려다보는 각도.
>
> **조명** — 큰 창에서 들어오는 부드러운 자연광, 중성 화이트 밸런스. 장갑의 직물
> 질감과 제품 표면에 같은 방향의 부드러운 하이라이트가 생긴다.
>
> **배경** — 목공 작업장. 클램프와 대팻밥이 뒤쪽에 흐릿하게 보인다. 다른 사람은 없다.
>
> 현장감 있는 상업 광고 사진.
> photorealistic commercial photography, natural window light, shallow depth of field,
> accurate hand anatomy, work gloves.
>
