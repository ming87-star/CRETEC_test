# 공구 상세페이지 생성기

제품 대표 사진과 카탈로그 가격표 캡쳐를 넣으면 쇼핑몰(네이버 860px · 쿠팡 780px · 토스 1080px)
상세페이지를 만드는 웹 도구입니다. 1 입력 → 2 초안 → 3 사진 생성·편집 → 4 저장.

## 여는 방법은 두 가지

| | 미리보기 판 (Claude 아티팩트 링크) | 로컬 서버 (내 컴퓨터에서 켬) |
|---|---|---|
| 어떻게 | 링크만 누르면 열림 | 아래 설치 뒤 `npm start` |
| 기획 AI | 보는 사람의 Claude | Gemini (내 API 키) |
| 웹에서 특징 찾기 | 안 됨 | 됨 |
| 4단계 이미지로 저장 | 됨 — 브라우저 안에서 그려서 ZIP 으로 내려받기 | 됨 — 헤드리스 브라우저로 찍어 `out/` 폴더에 저장 (더 정확) |
| 비용 | Claude 구독 사용량 | Gemini API 키 (건당 수백 원) |

미리보기 판의 저장은 섹션을 브라우저 안에서 그림으로 바꾸는 방식이라 글꼴·사진이 그대로 나오지만,
로컬 서버의 캡처가 기준입니다. 미묘하게 다르면 로컬 서버로 저장하세요.

## 작업은 자동으로 남고, 창 사이로 옮길 수 있습니다

- **자동 저장** — 바뀔 때마다 그 브라우저에 저장됩니다. 창을 닫았다가 다시 열면 위에 노란 띠로
  "지난 작업이 있습니다 — 이어서 하기 / 새로 시작" 을 묻습니다.
- **작업 ▾ 메뉴** (오른쪽 위)
  - `파일로 저장` → `브랜드-제품명-날짜.json` 한 파일. 다른 컴퓨터·다른 창에서 `파일 불러오기…` 또는 창에 끌어다 놓기.
  - `클립보드로 복사` → 파일 내려받기가 막힌 미리보기 판에서 씁니다. 다른 창에서 `붙여넣기로 불러오기`(또는 그냥 Ctrl+V).
  - `새 작업` → 지금 작업을 지우고 처음부터.
- 사진·가격표·초안·3단계에서 옮긴 개체까지 전부 들어갑니다. 파일 크기는 사진 수에 따라 수 MB.

## 로컬 서버 설치 (처음 한 번)

## 로컬 서버 설치 (처음 한 번)

1. **Node.js 설치** — https://nodejs.org 에서 LTS 버전을 받아 설치합니다. (Windows · Mac 모두)
2. **이 저장소 내려받기** — GitHub 에서 `Code → Download ZIP` 을 받아 풀거나,
   ```
   git clone https://github.com/ming87-star/CRETEC_test.git
   ```
3. **폴더에서 터미널 열기** — Windows 는 그 폴더에서 주소창에 `cmd` 라고 치면 열립니다. Mac 은 터미널에서 `cd 폴더경로`.
4. **의존성 설치** (한 번만)
   ```
   npm install
   ```
   4단계 저장은 PC 에 깔린 **크롬이나 엣지**를 그대로 씁니다. 둘 다 없을 때만 `npx playwright install chromium` 으로
   전용 브라우저(149MB)를 받습니다. 받다가 100% 에서 멈춘 것처럼 보이면 압축을 푸는 중이니 몇 분 기다리거나, 크롬이 있으면 닫아도 됩니다.
5. **API 키 넣기** — 폴더에 `.env.local` 이라는 파일을 만들고 한 줄 적습니다.
   ```
   GEMINI_API_KEY=여기에_키
   ```
   키는 https://aistudio.google.com 에서 만듭니다. 이 파일은 깃에 올라가지 않고, 브라우저로도 내려가지 않습니다.

## 켜기 (매번)

```
npm start
```
터미널에 `http://localhost:4173` 이 뜨면 그 주소를 브라우저(크롬 권장)에서 엽니다.
창을 닫아도 서버는 돌고 있으니, 끌 때는 터미널에서 `Ctrl+C`.

## 저장 (4단계)

1. 3단계에서 사진을 다 채우고 **다음** 또는 **이미지로 저장하기**.
2. 4단계에서 플랫폼(네이버·쿠팡·토스)과 품질을 고르고, 필요하면 **전체를 합친 한 장도** 체크.
3. **이미지로 저장** 을 누르면 섹션마다 한 장씩 `out/` 폴더에 `01-히어로.jpg`, `02-문제.jpg` … 로, 합본은 `00-전체.jpg` 로 저장됩니다.
   화면에 몇 장이 어디에 저장됐는지 뜹니다. 다시 저장하면 `out/` 을 비우고 새로 씁니다.
4. 가격 문구가 남아 있거나, 작성자가 아직 보지 않은 초안 문장이 있으면 저장 전에 경고합니다.

## 자주 걸리는 것

- **"GEMINI_API_KEY 가 없습니다"** — `.env.local` 파일 이름과 위치(저장소 뿌리)를 확인. 만든 뒤에는 서버를 껐다 켭니다.
- **"Gemini 402 … credits are depleted"** — 키의 선불 크레딧이 떨어진 것. AI Studio 에서 충전.
- **저장 단추가 잠겨 있고 "미리보기 판" 안내가 뜸** — 지금 창이 아티팩트 링크로 연 창입니다. `npm start` 로 켠 `localhost:4173` 창에서 저장합니다.
- 사진은 도구가 직접 만들지 않습니다. 사진 자리의 **프롬프트 복사** → 쓰던 생성형 AI 에 붙여 넣어 만들고 → 나온 사진을 이 창으로 끌어다 놓거나 `Ctrl+V`.

## 새 판으로 바꾸기 (업데이트)

ZIP 을 다시 받아 풀고, 그 안의 파일들을 기존 폴더(`C:\상세페이지`)에 **덮어쓰기** 하면 됩니다.
`.env.local` 과 `node_modules` 는 ZIP 에 없으니 그대로 남습니다. 서버가 켜져 있었으면 `Ctrl+C` 로 끄고 `npm start`.
`package.json` 이 바뀐 업데이트면 `npm install` 을 한 번 더.

## 개발

- 정적 호스팅용 묶음: `node scripts/build-web.js` → `dist/`
- 브라우저 안 저장용 글꼴: `node scripts/fetch-fonts.mjs` → `web/fonts/` (구글 폰트를 한글 전체만 남겨 woff2 로. `pyftsubset` 필요: `pip install fonttools brotli`). 깃에는 안 올라가고, 없으면 기본 글꼴로 저장된다.
- 서버 없이 섹션 이미지만 뽑기: `npm run export`
- 프롬프트 설계와 검증 기록: `docs/프롬프트-템플릿.md`
