# 공구 상세페이지 메이커

제품 대표 이미지 여러 장과 특징 몇 줄만 입력하면 **공구 제품 상세페이지**를 자동으로 만들어 주는 웹 페이지입니다.
만들어진 페이지는 화면 안에서 바로 클릭해 고치고, 항목을 더하거나 지울 수 있습니다.

빌드 도구나 서버가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

```
git clone <repo>
cd CRETEC_test
# index.html 더블클릭  (또는)
npx serve .
```

## 사용 흐름

1. **이미지 탭** — 대표 이미지를 끌어다 놓거나 클릭해서 여러 장 올립니다.
   업로드한 이미지는 가로 1600px로 자동 축소되며, 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.
2. **제품 탭** — 브랜드·제품명·모델명·헤드라인·배지 문구·키워드 태그를 입력합니다.
3. **특징 자동 입력** — 한 줄에 하나씩 특징을 적습니다. `제목 | 설명` 형식이면 설명까지 들어갑니다.

   ```
   강력한 200Nm 토크 | 녹슨 볼트도 한 번에 풀어내는 브러시리스 모터
   3단계 속도 조절 | 작업물에 맞춰 정밀하게 제어
   1.2kg 초경량 | 천장 작업에도 손목이 편안합니다
   ```

4. **상세페이지 자동 생성** 버튼을 누르면 핵심 포인트 → 특징 소개(좌우 교차) → 사용 장면 → 사양 → 구성품 →
   구매 안내 → 마무리 문구 순서로 페이지가 구성되고, 올린 이미지가 순서대로 배치됩니다.
5. **미리보기에서 직접 수정** — 글자를 클릭하면 그 자리에서 고쳐집니다.
   이미지를 클릭하면 교체할 이미지를 고를 수 있고, 미리보기 위로 파일을 바로 끌어다 놓아도 됩니다.
6. **HTML 내보내기** — 이미지까지 포함된 파일 하나로 저장됩니다. **PDF / 인쇄**로 PDF 저장도 가능합니다.

## 메인(첫 화면) 구성

**메인 탭**에서 첫 화면을 두 가지 형식 중에 고릅니다.

- **사진 위 문구** — 사진을 화면 가득 깔고 그 위에 문구를 얹습니다.
  제품명 → 모델명 → 두 줄 헤드라인 → 배지 문구가 세로로 놓이고, 아래에 브랜드가 들어갑니다.
- **사진 아래 문구** — 사진을 먼저 보여주고 그 아래에 제품 정보를 두는 기본 형식입니다.

사진 위 문구 형식에서 조절할 수 있는 항목:

| 항목 | 설명 |
|---|---|
| 사진 비율 | 3:5 · 4:5 · 3:4 · 1:1 · 16:9 |
| 문구 정렬 / 세로 위치 / 가로 이동 | 제품이 있는 쪽을 비워두고 문구를 배치 |
| 사진 어둡게 덮기 | 밝은 사진에서 흰 글씨가 묻힐 때 |
| 제품 컷 올리기 | 배경을 지운 투명 PNG를 배경 위에 얹고 크기·위치·그림자 조절 |

글자 크기는 사진 폭에 비례해서 정해지므로(`cqw`), 페이지 폭을 바꾸거나 휴대폰에서 열어도 비율이 유지됩니다.

## AI로 메인 사진 만들기

메인 탭 아래쪽에서 배경 사진을 생성할 수 있습니다. **API 키는 본인 것을 넣어야 합니다.**

1. 제공자를 고릅니다 — **Google Gemini** 또는 **OpenAI**
2. API 키를 붙여넣습니다 (이 브라우저에만 저장되고, 저장 파일·내보낸 HTML에는 들어가지 않습니다)
3. 만들 대상을 고릅니다
   - **제품이 있는 장면** — 설명한 공구까지 함께 생성됩니다. 실제 제품과 모양이 다를 수 있습니다.
   - **배경만** — 제품 없는 빈 장면을 만듭니다. 배경을 지운 실제 제품 사진을 위에 올리면 실물 그대로 나옵니다. **이쪽을 권합니다.**
4. 장면(잔디 마당 · 목공 작업대 · 건설 현장 · 차고 · 스튜디오 · 야외 데크), 조명, 비율을 고르면
   영문 프롬프트가 자동으로 만들어집니다. 그대로 보내도 되고 직접 고쳐도 됩니다.
5. **메인 사진 생성**을 누르면 결과가 이미지 목록에 추가되고 메인 배경으로 들어갑니다.

### 어디서 동작하나요

브라우저가 이미지 생성 API로 직접 요청을 보내는 방식이라, **외부 요청이 허용된 곳에서만** 동작합니다.

| 실행 위치 | AI 생성 |
|---|---|
| `npx serve .` 로 띄운 로컬 서버 | ✅ 동작 |
| `index.html` 을 파일로 직접 열기 | ⚠️ 브라우저가 교차 출처 요청을 막을 수 있음 |
| 배포된 아티팩트 미리보기 | ❌ 보안 정책(CSP)으로 외부 요청 차단 |

아티팩트에서는 생성 대신 **이미지 업로드**를 쓰시면 나머지 기능은 모두 그대로 동작합니다.

## 페이지 안에서 할 수 있는 편집

| 대상 | 방법 |
|---|---|
| 글자 | 클릭 후 바로 입력 (붙여넣기는 서식 없이 들어갑니다) |
| 이미지 | 이미지 영역 클릭 → 선택 모달, 또는 파일 드래그 |
| 항목 추가 | 각 섹션 하단의 `+ 항목 추가` |
| 항목 삭제 | 항목 옆 `삭제` / `×` |
| 섹션 이동·복제·삭제 | 섹션에 마우스를 올리면 우측 상단에 도구가 나타납니다 |
| 섹션 추가·숨김 | 좌측 **섹션** 탭 |

`편집 모드`를 끄면 편집용 요소가 사라진 실제 화면을 확인할 수 있습니다.

## 섹션 종류

대표 이미지 · 핵심 포인트 · 특징 소개 · 이미지 갤러리 · 사용 장면 · 제품 사양 · 구성품 · 구매 안내 · 마무리 문구 · 자유 텍스트

## 디자인 설정

- 테마 3종: 인더스트리얼 / 클린 화이트 / 모던 다크
- 포인트 컬러, 페이지 폭(640~1000px), 모서리 둥글기, 제목 크기
- POINT 번호 표시, 하단 브랜드 문구 표시

## 저장

상단 **저장** 버튼(또는 `Ctrl/Cmd + S`)을 누르면 브라우저 `localStorage`에 작업 내용이 보관되고,
**불러오기**로 복원합니다. 이미지가 많으면 저장 용량을 초과할 수 있으므로, 완성본은 **HTML 내보내기**로 남겨두세요.

## 파일 구성

```
index.html          에디터 화면
build.js            단일 파일 빌드 (node build.js → dist/standalone.html)
css/app.css         에디터 UI 스타일
js/page-css.js      생성되는 상세페이지 스타일 (미리보기 주입 + 내보내기에 함께 저장)
js/state.js         상태 · 섹션 정의 · 자동 구성 · 저장/불러오기
js/ai.js            AI 이미지 생성 (프롬프트 빌더 · 제공자별 호출 · 응답 파싱)
js/render.js        상태 → 상세페이지 HTML 렌더링
js/panel.js         좌측 패널 UI
js/app.js           이벤트 연결 · 이미지 처리 · 내보내기
```

AI 생성을 쓰지 않으면 네트워크 요청이 전혀 없어 오프라인에서도 그대로 동작합니다.
외부 라이브러리는 어느 경우에도 사용하지 않습니다.
