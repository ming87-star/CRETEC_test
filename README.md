# 공구 상세페이지 메이커

브랜드 · 제품명, 대표 이미지, 제품 특징 세 가지를 넣으면 **AI가 이 제품에 맞는 공구 상세페이지를
설계하고 사진까지 만들어** 완성해 주는 웹 도구입니다. 만들어진 페이지는 화면 안에서 바로 클릭해
고치고, 항목을 더하거나 지울 수 있습니다.

빌드 도구가 없습니다. 다만 AI 호출은 브라우저에서 직접 나가므로 로컬 서버로 띄우는 편이 안전합니다.

```
git clone <repo>
cd CRETEC_test
# index.html 더블클릭  (또는)
npx serve .
```

## 사용 흐름

세 가지만 넣고 **상세페이지 생성**을 누르면, AI가 이 제품에 맞는 구성을 설계하고
필요한 사진까지 만들어 완성본을 내놓습니다. 입력하는 족족 템플릿이 채워지는 방식이 아니라,
한 번에 판단해서 페이지를 짜는 방식입니다.

1. **브랜드 · 제품명**
2. **대표 이미지** — 생성되는 모든 컷의 참조로 쓰입니다. 실제 제품이 사진에 나오게 하는 근거입니다.
3. **제품 특징** — 한 줄에 하나씩. 아는 수치는 그대로 적어주세요.

여기에 AI 제공자와 API 키를 넣고 버튼을 누르면 두 단계로 진행됩니다.

| 단계 | 하는 일 |
|---|---|
| 구성 설계 | 어떤 섹션을 몇 개 어떤 순서로 둘지, 헤드라인·배지·섹션 문구를 무엇으로 쓸지, 각 자리에 어떤 사진이 필요한지를 한 번에 설계 |
| 사진 생성 | 설계된 촬영 레시피대로 자리마다 사진을 순차 생성 (최대 12장) |

진행 상황이 단계별로 표시되고, **같은 버튼을 다시 누르면 중단**됩니다. 중단해도 그때까지
만들어진 내용은 그대로 남습니다.

### 사양을 지어내지 않습니다

`전압`, `무게`, `구성품`처럼 입력에 없는 값은 **빈 칸으로 남깁니다.** AI에게 그럴듯한
숫자를 채우지 말라고 지시하고, 결과에서 빈 칸을 직접 세어 **채워야 할 항목** 목록으로
보여줍니다. 미리보기에서도 해당 칸에 점선이 표시됩니다. 실제 판매 페이지에 틀린 사양이
실리는 사고를 막기 위한 것입니다.

### AI 없이 쓰기

**AI 없이 규칙만으로 구성**을 켜면 API 호출 없이 즉시 페이지가 나옵니다. 특징 문장에서
`200Nm`, `1.2kg` 같은 수치만 뽑아 사양표에 넣고 나머지는 비워둡니다. API 호출이 실패해도
이 방식으로 다시 시도하도록 안내합니다.

### 생성 후

생성 결과는 시작점입니다. 미리보기에서 글자를 직접 고치고, 섹션을 옮기거나 지우고,
사진을 바꾸는 기능은 그대로 있습니다.

## 메인(첫 화면) 구성

**메인 탭**에서 첫 화면을 두 가지 형식 중에 고릅니다.

- **사진 위 문구** — 사진을 화면 가득 깔고 그 위에 문구를 얹습니다.
  제품명 → 모델명 → 두 줄 헤드라인 → 배지 문구가 세로로 놓이고, 아래에 브랜드가 들어갑니다.
- **사진 아래 문구** — 사진을 먼저 보여주고 그 아래에 제품 정보를 두는 기본 형식입니다.

사진 위 문구 형식에서 조절할 수 있는 항목:

| 항목 | 설명 |
|---|---|
| 사진 비율 | 3:5 · 4:5 · 3:4 · 1:1 · 16:9 |
| 문구 정렬 / 세로 위치 / 가로 이동 | 제품이 있는 쪽을 비워두고 문구를 배치 |
| 사진 어둡게 덮기 | 밝은 사진에서 흰 글씨가 묻힐 때 |
| 제품 컷 올리기 | 배경을 지운 투명 PNG를 배경 위에 얹고 크기·위치·그림자 조절 |

글자 크기는 사진 폭에 비례해서 정해지므로(`cqw`), 페이지 폭을 바꾸거나 휴대폰에서 열어도 비율이 유지됩니다.

## AI로 제품 사진 만들기

메인 탭 아래쪽에 있습니다. **제품의 어떤 특징을 보여줄 사진인가**를 정하면 앵글·조명·배경·소품이
따라오는 방식입니다. **API 키는 본인 것을 넣어야 합니다.**

### 무엇을 정하나요

| 항목 | 내용 |
|---|---|
| 컷 종류 | 히어로 · 디테일 매크로 · 사용 중 액션 · 크기 비교 · 구성품 배치 |
| 강조할 특징 | 페이지에 적어둔 특징 목록에서 고르거나 직접 입력 |
| 연출 방식 | 파워·토크 / 경량 / 내구성 / 정밀 / 배터리 / 그립 / 속도 / 다용도 — **자동**이면 특징 문장에서 판단 |
| 배경 | 무채색 콘크리트 · 블랙 로우키 · 화이트 무한대 · 목공 작업대 · 건설 현장 · 잔디 마당 · 차고 · 인테리어 현장 |
| 조명 | 하드 측광 · 소프트박스+림 · 로우키 · 하이키 · 골든아워 · 창가 자연광 |
| 후보 장수 | 1~4장을 만들어 놓고 마음에 드는 것을 고름 |
| 넣을 자리 | 메인 배경 / 메인 제품 컷 / 특징 섹션 / 사용 장면 / 갤러리 / 목록에만 담기 |

배경과 조명은 기본이 **자동**입니다. 내구성을 강조하면 콘크리트에 하드 측광이, 경량을 강조하면
화이트 배경에 하이키 조명이 붙는 식입니다. 직접 고르면 자동 선택을 덮어씁니다.

### 프롬프트

고른 값들이 촬영 지시서 형태로 조립됩니다 — 프레이밍 → 강조 전략 → 배경 → 조명 → 카메라 →
마감 → 여백 → 금지 항목. 히어로 컷일 때만 헤드라인용 상단 여백을 요구하고, 액션 컷일 때만 손이
허용됩니다. 만들어진 문장은 그대로 보여지므로 직접 고쳐서 보낼 수 있습니다.

### 실제 제품 그대로 나오게 하기

**실제 제품 사진을 참조로 첨부**를 켜고 올려둔 제품 사진을 고르면, 그 사진을 함께 보내
같은 제품을 장면 안에 그리도록 지시합니다. 이걸 켜지 않으면 AI가 상상한 공구가 나오므로,
실물이 중요하다면 반드시 켜세요. 배경이 지워진 정면 사진일수록 정확합니다.

### 매번 키를 넣기 귀찮다면

`js/local-key.js` 파일을 만들어 두면 API 키 칸이 자동으로 채워집니다.

```js
window.LOCAL_AI_KEY = '여기에 키';
```

이 파일은 `.gitignore` 에 있어 **커밋되지 않고**, `build.js` 도 번들에 넣지 않습니다.
키가 작업 폴더 밖으로 나가지 않습니다. 파일이 없어도 앱은 그대로 동작합니다.

### 어디서 동작하나요

브라우저가 이미지 생성 API로 직접 요청을 보내는 방식이라, **외부 요청이 허용된 곳에서만** 동작합니다.

| 실행 위치 | AI 생성 |
|---|---|
| `npx serve .` 로 띄운 로컬 서버 | ✅ 동작 |
| `index.html` 을 파일로 직접 열기 | ⚠️ 브라우저가 교차 출처 요청을 막을 수 있음 |
| 배포된 아티팩트 미리보기 | ❌ 보안 정책(CSP)으로 외부 요청 차단 |

아티팩트에서는 생성 대신 **이미지 업로드**를 쓰시면 나머지 기능은 모두 그대로 동작합니다.

## 페이지 안에서 할 수 있는 편집

| 대상 | 방법 |
|---|---|
| 글자 | 클릭 후 바로 입력 (붙여넣기는 서식 없이 들어갑니다) |
| 이미지 | 이미지 영역 클릭 → 선택 모달, 또는 파일 드래그 |
| 항목 추가 | 각 섹션 하단의 `+ 항목 추가` |
| 항목 삭제 | 항목 옆 `삭제` / `×` |
| 섹션 이동·복제·삭제 | 섹션에 마우스를 올리면 우측 상단에 도구가 나타납니다 |
| 섹션 추가·숨김 | 좌측 **섹션** 탭 |

`편집 모드`를 끄면 편집용 요소가 사라진 실제 화면을 확인할 수 있습니다.

## 섹션 종류

대표 이미지 · 핵심 포인트 · 특징 소개 · 이미지 갤러리 · 사용 장면 · 제품 사양 · 구성품 · 구매 안내 · 마무리 문구 · 자유 텍스트

## 디자인 설정

- 테마 3종: 인더스트리얼 / 클린 화이트 / 모던 다크
- 포인트 컬러, 페이지 폭(640~1000px), 모서리 둥글기, 제목 크기
- POINT 번호 표시, 하단 브랜드 문구 표시

## 저장

상단 **저장** 버튼(또는 `Ctrl/Cmd + S`)을 누르면 브라우저 `localStorage`에 작업 내용이 보관되고,
**불러오기**로 복원합니다. 이미지가 많으면 저장 용량을 초과할 수 있으므로, 완성본은 **HTML 내보내기**로 남겨두세요.

## 파일 구성

```
index.html          에디터 화면
build.js            단일 파일 빌드 (node build.js → dist/standalone.html)
css/app.css         에디터 UI 스타일
js/page-css.js      생성되는 상세페이지 스타일 (미리보기 주입 + 내보내기에 함께 저장)
js/state.js         상태 · 섹션 정의 · 저장/불러오기
js/ai.js            AI 호출 (촬영 지시서 조립 · 이미지/글 생성 · 제공자별 요청 · 응답 파싱)
js/plan.js          페이지 설계 (설계 지시문 · 결과 검증 · 상태 반영 · 규칙 기반 대체)
js/render.js        상태 → 상세페이지 HTML 렌더링
js/panel.js         좌측 패널 UI
js/app.js           이벤트 연결 · 이미지 처리 · 내보내기
```

AI 생성을 쓰지 않으면 네트워크 요청이 전혀 없어 오프라인에서도 그대로 동작합니다.
외부 라이브러리는 어느 경우에도 사용하지 않습니다.
